# Data credit

`nodeLibrary.json` is the block/action node database (345 node definitions
across 16 categories) reused from **[Scriptilyx SE](https://github.com/ChaosVROne/Scriptilyx-SE)**
by ChaosVROne / Parallel Infinite Worlds Company, shipped publicly as part
of that project's own releases. It's plain data — block names, categories,
action ids, UI copy — not source code from that project. See
`../../docs/PLAN.md` → "IP handling" for the reasoning.
