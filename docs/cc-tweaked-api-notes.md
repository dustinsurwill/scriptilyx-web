# CC:Tweaked — codegen reference notes

Working notes gathered while implementing `src/games/cc-tweaked/codegen/generate.ts`, `src/games/cc-tweaked/nodeLibrary.ts`, and `src/games/cc-tweaked/advancedPeripherals.ts`. Our own summary of publicly documented API facts, not a copy of any wiki's prose and not derived from any third-party tool's source — see `CLAUDE.md` → "Hard constraints" for why that distinction matters; the Space Engineers and Stationeers IC10 equivalents of this file are `docs/space-engineers-codegen-api-notes.md` and `docs/ic10-api-notes.md`.

Sources:
- **CC:Tweaked base API**: the mod's own public Lua API documentation, tweaked.cc — specifically the `turtle`, `redstone`, `peripheral`, `rednet`, `gps`, `os`, and `colors` module pages, which document every global function this catalog's base nodes compile to (`turtle.forward`, `turtle.dig`, `redstone.getInput`, `peripheral.call`, `rednet.receive`, `gps.locate`, `os.sleep`, and so on).
- **Advanced Peripherals addon**: the mod's own public documentation site, docs.intelligence-modding.de, which documents each peripheral's Lua method surface (ME Bridge, RS Bridge, Chat Box, Redstone Integrator, Colony Integrator, Environment Detector, Player Detector, Energy Detector).

## Why this backend's codegen shape differs from Stationeers IC10's

IC10 (see `docs/ic10-api-notes.md`) has a hard 128-line/90-char-per-line cap and no real function-call concept — every node compiles to a flat, label-and-jump instruction sequence. CC:Tweaked has neither constraint: real Lua functions, no line cap, and its blocking calls (`os.pullEvent` under the hood of `os.sleep`, `turtle.forward()`, `rednet.receive()`, ...) already yield to the game's own coroutine scheduler, so a node-graph-as-flowchart compiles directly to sequential Lua rather than needing an event-handler-registration shape. This makes the codegen structurally closer to Space Engineers' one-function-per-node approach than to IC10's flat line list — see `docs/PLAN.md`'s "CC:Tweaked" architecture section for the fuller comparison.

## Program shape (`generateScript` in `src/games/cc-tweaked/codegen/generate.ts`)

- Reuses `findStartNodes`/`getReachableNodeIds` from `src/lib/graph.ts` as-is — already fully game-agnostic (the same confirmation Stationeers IC10 gave this claim).
- Every reachable node compiles to one Lua function, `stepN` (`N` = the node's `Number`), each doing its own statement(s) then either falling through to the next node's function or branching between two of them.
- **Forward declaration is required**: Lua's `local function foo() ... end` sugar can't forward-reference a sibling declared later in the same block, and this app's graphs commonly branch forward (an `if` node calling a function defined further down the file). So every step function is declared as a bare `local stepN` up front, then assigned its body afterward (`stepN = function() ... end`) — the standard two-step pattern for mutually-referencing local Lua functions.
- **Tail calls, not full calls**: every "go to the next node" is emitted as `return stepN()`, a genuine Lua tail call (only valid in that exact `return f(...)` form) rather than a bare `stepN()` followed by falling off the end of the function. This matters because CC:Tweaked programs commonly loop forever (a turtle mining loop, a redstone monitor loop, ...) — without tail calls, each iteration would push a new stack frame and the script would eventually hit Lua's call-stack limit; with them, looping runs in O(1) stack space indefinitely, exactly as if it were a real `while true do ... end` loop.
- **Variables**: unlike IC10 (16 hard-capped registers), Lua locals are unlimited, so there's no allocator/cap — every node whose properties declare a named variable (`Set Variable`'s `Name`, `Number Math`'s `Name`, `Get GPS Position`'s `NameX`/`NameY`/`NameZ`, and so on — see `DECLARING_PROPERTIES` in `generate.ts`) just gets a `local` declared once, up front, above all the step functions, so it's a shared upvalue every step function can read and write. The only validation is that the declared name is a legal, non-reserved Lua identifier (warns and skips declaring it otherwise — referencing an undeclared name still generates, it just falls through to being treated as literal text, same "generate best-effort, warn" posture the rest of this app uses).
- **No hard size cap, no minifier**: nothing about CC:Tweaked forces either — Lua source has no equivalent line/char limit the game enforces, so `Game.lineLimit`/`Game.charLimit`/`Game.minify` are all left unset for this game (see `src/games/cc-tweaked/index.ts`).

## Node catalog scope (`src/games/cc-tweaked/nodeLibrary.ts`, 47 nodes)

Built for non-engineers, not as a minimal proof-of-concept — unlike IC10, where the hard line cap makes a small catalog the *correct* choice regardless of scope, CC:Tweaked has no such constraint, so this catalog aims for the same comprehensiveness standard as Space Engineers' (streamlined — one node per distinct capability, a Direction/Side combo instead of duplicate per-direction node pairs — not thin). Covers: control flow (Start/Wait/Loop/Print/Custom Code), numeric and text comparison, variables/math/text-join, generic peripheral wrapping + the universal `peripheral.call` escape hatch, redstone I/O, rednet networking (open/host/send/broadcast/receive), turtle movement/world-interaction/inventory/navigation, monitor drawing, speaker sound, and disk drive presence/eject. "Custom Code" exists as a last resort for the rare gap, not as a substitute for a dedicated node — see `docs/PLAN.md` for the fuller per-category breakdown.

## Advanced Peripherals addon (`src/games/cc-tweaked/advancedPeripherals.ts`, 22 nodes)

Gated behind a palette toggle (`Game.addons`, see `docs/PLAN.md`'s "Multi-game architecture" section) since these peripherals only exist for players who actually have the mod installed — toggling it off never breaks a graph that already uses one of its nodes, since codegen has no concept of the toggle at all (an addon node's `ActionType` is registered in the exact same emitter switch as every base node). Covers ME Bridge and RS Bridge (list/get-count/push/pull/craft — both storage mods expose the same method shape, so their nodes are near-identical pairs), Chat Box (server + private messages), Redstone Integrator (any-side digital I/O, not just the block's own six sides), Colony Integrator (MineColonies stats), Environment Detector (time/moon phase/light level), Player Detector (in-range check, nearest player), and Energy Detector (stored/flow). Every node still compiles through the generic `peripheral.call(side, "methodName", ...)` shape the base catalog's own "Call Peripheral Method" node uses — these are pre-filled convenience wrappers around that same call, not a separate codegen path.
